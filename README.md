# AQI India Dashboard

Interactive Power BI dashboard analyzing air quality across Indian cities and states.

## Features
- KPI Cards
- AQI Trend Analysis
- Pollutant-wise Analysis
- Scatter Chart
- City-wise AQI Comparison
- Interactive Filters
- Dark Theme UI

## Tools Used
- Power BI
- DAX
- Power Query
